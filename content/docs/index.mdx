# Introduction

TeamComms is a real-time team communication platform built with Next.js, oRPC, and PartySocket. It started as a learning project and is now actively growing with new features such as AI-assisted chat, rich-text collaboration, and file sharing.

## Tech stack used:

High-level overview. See [Tech Stack](/docs/introduction/tech-stack) for the detailed reasoning and comparisons.

- **Framework** — Next.js (App Router) with React 19
- **API layer** — oRPC + TanStack Query
- **Realtime** — PartySocket / PartyServer
- **Database** — PostgreSQL with Prisma ORM
- **Auth** — Better Auth
- **AI** — Vercel AI SDK via OpenRouter
- **UI** — Tailwind CSS, shadcn/ui, Base UI, Radix UI
- **Editor** — Tiptap rich-text editor
- **Docs** — Fumadocs (this site)
- **Files** — UploadThing
- **Tooling** — Biome, TypeScript
- **Security** — Arcjet
- **Deploy** — Vercel
